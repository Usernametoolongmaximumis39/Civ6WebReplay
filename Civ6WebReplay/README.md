# Civ6 WebReplay

[简体中文](README.md) | [English (AI-generated)](README.en.md)

Civ6 WebReplay 是《文明 VI》的浏览器复盘工具。选择一组游戏存档，就可以沿回合查看地图、城市、单位和各文明的数据变化。

当前版本：**v0.44**。推荐在 Windows 上使用，配合 Chrome 或 Edge 浏览器。

- 新增伟人信息面板，展示当前可招募伟人、所需点数及各文明的伟人点数与每回合产出。

- 随应用附带科研造价规则与伟人名称数据，更新复盘缓存以适配新字段。

## 能查看什么

- 回合地图：城市、区域、建筑、改良、资源、道路、河流、单位和迷雾。
- 城市与单位详情：人口、生产队列、已建建筑、掠夺状态、血量、总督和单位晋升。
- 文明数据与独立对比页：科技、市政、经济、军事、文化、外交等数据。
- 文明与领袖技能、政策卡名称及说明，点击头像或政策标题展开。
- 地块六种产出及来源明细、区域相邻加成；原版、BBG、CCB 按各自规则集显示。
- 地图图层、缩放与布局偏好保存，以及大陆透镜、奢侈资源高亮。
- 主动开启共享后，让同一网络中能访问本机的人通过浏览器查看复盘。

## 安装和启动

1. 安装 [Python 3.11 或更新版本](https://www.python.org/downloads/)。安装时勾选 **Add Python to PATH**。
2. 在 GitHub 仓库点击 **Code → Download ZIP**，解压到本地文件夹。
3. 打开解压后的 **Civ6WebReplay** 文件夹，双击 **start.bat**。
4. 首次启动会检查并安装所需依赖，需要联网。默认打开 `http://127.0.0.1:8765/`；若端口已被占用，会自动选用可用端口并打开对应地址。
5. 使用完成后，在启动窗口按 **Ctrl+C** 关闭服务。

已经包含运行所需的规则和图标数据，无需自行构建资源。程序不会修改游戏存档。

生产队列的分母是所需总产能。政策卡、世界议会等生产速度修正影响每回合投入，不直接改变这个分母；城市产出栏读取存档保存的城市总产出，不另行估算针对某个单位的有效生产速度。区域使用存档中锁定的造价；修复城防等无法可靠确定造价的特殊项目仍显示 `?`。

## 选择存档并复盘

点击网页顶部的 **打开存档**，可选择单个 `.Civ6Save` 文件或存档文件夹，也可将文件或文件夹直接拖到页面上。单文件会自动打开对应回合；文件夹会按对局和回合整理多个存档。路径框也支持直接粘贴文件或目录路径。程序默认读取：

```text
%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Saves\Multi\auto
```

单人存档通常位于 `Saves\Single` 或其 `auto` 子目录。通过路径框、目录树或「浏览…」打开目录时，只扫描目录直属的存档，刷新可发现新增存档。通过「选择文件夹…」或拖拽导入时，会读取子目录中的存档，并使用本次进程内的副本；原目录新增存档后需重新导入。如果文档文件夹被 OneDrive 或其他设置重定向，请选择实际位置。

## 语言

顶部语言菜单默认为 **自动**：浏览器首选语言为中文时显示简体中文，否则显示英文。也可手动选择中文或 English；选择会保存在本机，并应用于独立对比页和共享访客页面。游戏文本按原版、BBG 或 CCB 规则集分别查找英文；某条模组文本没有英文时，不会借用原版描述。

选择一局回放后，用回合控制切换回合；点击地图格子查看详情，通过 **信息、产出、区域、单位** 页签切换内容。打开 **对比** 可在新页面比较各文明的数据。新增存档后点击 **刷新存档**。

复盘只能展示已有存档对应的回合。想保留更多回合，请在游戏中提高自动存档频率，并保留足够数量的自动存档。

无法识别的宗教统一显示为「未知宗教1」「未知宗教2」等，并借用本局最新存档的完整创教名单中未使用的宗教图标。同一宗教在各回合、文明详情、城市详情和地图上使用相同的编号与图标；仅在已创立的回合显示。可用宗教图标耗尽时使用通用信仰图标。

## 原版、BBG 与 CCB

工具根据存档中的模组信息选择对应规则集，不会用另一套规则替代缺失的规则。顶部右侧的“对局信息”按钮可展开地图设置、数据库所属版本、存档版本及本局启用的 MOD 清单（不列出官方 DLC）。

BBG / CCB 主模组与文明拓展分别识别，地图、多人助手、兼容补丁不视为主模组。Beta（含 BETA、测试版）和 WIP 开发版会在顶部及版本提示中分别标注，主模组与拓展可属于不同渠道。识别支持更新后变化的 MOD ID；缺少渠道证据时保留未知，不将数据库快照的渠道或版本套用到旧存档。采集记录保留模组清单中的两个原始数字版本字段。

政策和技能说明、独有内容的图标与配色也会按规则集选择。额外模组并不都能正确复盘；涉及未支持的效果或存档状态时，界面会显示缺项或不可用。

地块产出中的 **已计算产出** 表示仍存在未覆盖条件。灾害额外肥力读取存档中的累计地块额外产出；城市级乘数、贸易路线、住房、电力和旅游业绩不计入地块产出数值。区域相邻数值也不等于区域的全部收益。

以下情况目前不支持：

- 秘密结社、垄断与公司玩法。
- 标题含“结社”的模组、CCB“受命于天”或“纪元回响”。
- 改写规则的 Team PVP 模组；已识别的界面辅助组件除外。

## 规则数据库

程序使用随附的原版、BBG、CCB 运行数据。旧数据库采集与回档入口已移除，等待重做；当前请使用完整程序包中的规则快照。

## 共享复盘

点击顶部 **共享**，按页面提示开启共享并复制链接给其他人。默认共享端口从 **8766** 开始选择；主页面默认使用 **8765**，占用时自动改用其他端口。

其他人的设备需要能通过局域网、虚拟局域网或配置好的公网入口访问你的电脑。公网使用可能需要端口映射和防火墙放行，复制链接不代表网络一定可达。共享服务没有登录验证，只应提供给希望其查看复盘的人。

共享期间存档目录和刷新操作会被锁定；停止共享后恢复。关闭程序也会停止共享。

## 常见问题

**双击后提示找不到 Python？**

重新安装 Python 并勾选 Add Python to PATH，或确认命令行可以执行 `python --version`。安装后重新打开启动窗口。

**网页没有回放？**

确认选择的目录直接包含 `.Civ6Save` 文件，并点击刷新。只有一个回合的存档无法展示完整历史。

**希望指定主页面端口？**

在 Civ6WebReplay 文件夹打开终端，运行以下命令。若指定端口也被占用，程序会自动选择可用端口：

```powershell
.\start.bat --port 9000
```

也可以启动时指定存档目录：

```powershell
.\start.bat --save-dir "D:\Civ6Saves"
```

**第一次加载较慢？**

首次扫描使用多线程读取存档，后台使用多个进程并行解析回合，默认并发数为 CPU 逻辑线程数的一半，向下取整且至少为 1。例如 8 核 16 线程的 CPU 默认使用 8 路并行。各回合完成后立即可用，无需等待前面的回合。解析结果保存在 `cache\replay.sqlite`，后续加载通常更快。关闭程序后可以删除这个缓存，但下一次会重新解析。

可通过 `.\start.bat --load-workers 2` 调整并发数（1–16），或设置环境变量 `CIV6_REPLAY_WORKERS`。设为 `1` 使用串行加载；提高并发数会增加 CPU 和内存占用。

**地图或某项产出显示不可用？**

查看界面提示的具体原因，检查存档玩法、模组及数据库规则集。确认使用的程序包包含对应规则数据；尚未实现的效果仍会提示缺项。旧采集功能目前已停用。
