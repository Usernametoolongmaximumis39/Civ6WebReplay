# Civ6 WebReplay

[简体中文](README.md) | [English (AI-generated)](README.en.md)

Civ6 WebReplay 是《文明 VI》的浏览器复盘工具。选择一组游戏存档，就可以沿回合查看地图、城市、单位和各文明的数据变化。

当前版本：**v0.42**。推荐在 Windows 上使用，配合 Chrome 或 Edge 浏览器。

## v0.42 更新

- 新增中英文界面，可自动识别浏览器语言，也可手动切换并保存选择。
- 英文显示会按规则集选择游戏文本；BBG / CCB 主模组、文明拓展及 Beta / WIP 渠道分别识别。
- 更新 CCB 1.8 规则数据采集；缺失的 Lua 脚本会如实标明，不伪造采集结果。

## 能查看什么

- 回合地图：城市、区域、建筑、改良、资源、道路、河流、单位和迷雾。
- 城市与单位详情：人口、生产队列、已建建筑、掠夺状态、血量、总督和单位晋升。
- 文明数据与独立对比页：科技、市政、经济、军事、文化、外交等数据。
- 文明与领袖技能、政策卡名称及说明，点击头像或政策标题展开。
- 地块六种产出及来源明细、区域相邻加成；原版、BBG、CCB 按各自规则集显示。
- 地图图层、缩放与布局偏好保存，以及大陆透镜、奢侈资源高亮。
- 主动开启共享后，让同一网络中能访问本机的人通过浏览器查看复盘。

## 安装和启动

1. 安装 [Python 3.11 或更新版本](https://www.python.org/downloads/)。安装时勾选 **Add Python to PATH**。
2. 在 GitHub 仓库点击 **Code → Download ZIP**，解压到本地文件夹。
3. 打开解压后的 **Civ6WebReplay** 文件夹，双击 **start.bat**。
4. 首次启动会检查并安装所需依赖，需要联网。之后浏览器自动打开 `http://127.0.0.1:8765/`。
5. 使用完成后，在启动窗口按 **Ctrl+C** 关闭服务。

已经包含运行所需的规则和图标数据，无需自行构建资源。程序不会修改游戏存档。

## 选择存档并复盘

点击网页顶部的 **存档目录**，选择包含 `.Civ6Save` 文件的目录。程序默认读取：

```text
%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Saves\Multi\auto
```

单人存档通常位于 `Saves\Single` 或其 `auto` 子目录。选择直接存放存档文件的文件夹；程序不会递归扫描全部子目录。如果文档文件夹被 OneDrive 或其他设置重定向，请在界面中手动选择实际位置。

## 语言

顶部语言菜单默认为 **自动**：浏览器首选语言为中文时显示简体中文，否则显示英文。也可手动选择中文或 English；选择会保存在本机，并应用于独立对比页和共享访客页面。游戏文本按原版、BBG 或 CCB 规则集分别查找英文；某条模组文本没有英文时，不会借用原版描述。

选择一局回放后，用回合控制切换回合；点击地图格子查看详情，通过 **信息、产出、区域、单位** 页签切换内容。打开 **对比** 可在新页面比较各文明的数据。新增存档后点击 **刷新存档**。

复盘只能展示已有存档对应的回合。想保留更多回合，请在游戏中提高自动存档频率，并保留足够数量的自动存档。

## 原版、BBG 与 CCB

工具根据存档中的模组信息选择对应规则集，不会用另一套规则替代缺失的规则。顶部平衡模组旁的问号可查看数据库版本和存档记录的版本。

BBG / CCB 主模组与文明拓展分别识别，地图、多人助手、兼容补丁不视为主模组。Beta（含 BETA、测试版）和 WIP 开发版会在顶部及版本提示中分别标注，主模组与拓展可属于不同渠道。识别支持更新后变化的 MOD ID；缺少渠道证据时保留未知，不将数据库快照的渠道或版本套用到旧存档。采集记录保留模组清单中的两个原始数字版本字段。

政策和技能说明、独有内容的图标与配色也会按规则集选择。额外模组并不都能正确复盘；涉及未支持的效果或存档状态时，界面会显示缺项或不可用。

地块产出中的 **已计算产出** 表示仍存在未覆盖条件。灾害额外肥力、城市级乘数、贸易路线、住房、电力和旅游业绩不计入地块产出数值。区域相邻数值也不等于区域的全部收益。

以下情况目前不支持：

- 秘密结社、垄断与公司玩法。
- 标题含“结社”的模组、CCB“受命于天”或“纪元回响”。
- 改写规则的 Team PVP 模组；已识别的界面辅助组件除外。

## 采集或更新 BBG / CCB 数据库

通常可以直接使用自带数据。需要匹配新的 BBG / CCB 规则时，再进行采集：

1. 关闭正在运行的 Civ6 WebReplay。
2. 双击 **capture_database.bat**，选择 **BBG** 或 **CCB**，再选择采集新数据。
3. 按窗口提示启用目标核心及已识别配套模组，开启一局单人游戏。不要混装 BBG 和 CCB，关闭额外规则模组及不支持的玩法。
4. 在收到准备提示之后，进入游戏并重新保存一次，保持当前游戏会话开启。
5. 返回采集窗口，输入 **Y**；核对检测到的存档路径，按提示完成采集。
6. 成功后重新启动 Civ6 WebReplay。

采集会保存当前生效的规则、本地化文本和模组游戏脚本，并更新政策/技能文本、地块产出、区域相邻及总督资料。未支持的规则或 Lua 效果不会因为重新采集而自动得到计算支持。

若无法检测游戏安装目录、缓存目录或存档，窗口会要求输入实际路径。存档过旧、模组不匹配或数据库发生变化时，采集会拒绝切换数据。

支持“CCB正式版1.8”等新版名称。若模组清单引用了安装包中不存在的 Lua 脚本，采集会提示并在记录中标明缺项，继续保存实际生效的数据库；不会补造脚本或将其标为已采集。

### 备份和回档

每次采集前自动备份原有数据，历史备份保存在 `data\backups\bbg` 或 `data\backups\ccb`。再次打开 **capture_database.bat**，选择对应规则集，即可按时间和版本回档或删除指定历史备份。

回档也会保留当前数据作为备份。采集或回档成功后，需要重新启动复盘工具；游戏存档不会被覆盖。

## 共享复盘

点击顶部 **共享**，按页面提示开启共享并复制链接给其他人。默认共享端口从 **8766** 开始选择；主页面仍使用 **8765**。

其他人的设备需要能通过局域网、虚拟局域网或配置好的公网入口访问你的电脑。公网使用可能需要端口映射和防火墙放行，复制链接不代表网络一定可达。共享服务没有登录验证，只应提供给希望其查看复盘的人。

共享期间存档目录和刷新操作会被锁定；停止共享后恢复。关闭程序也会停止共享。

## 常见问题

**双击后提示找不到 Python？**

重新安装 Python 并勾选 Add Python to PATH，或确认命令行可以执行 `python --version`。安装后重新打开启动窗口。

**网页没有回放？**

确认选择的目录直接包含 `.Civ6Save` 文件，并点击刷新。只有一个回合的存档无法展示完整历史。

**默认端口被占用？**

在 Civ6WebReplay 文件夹打开终端，运行：

```powershell
.\start.bat --port 9000
```

也可以启动时指定存档目录：

```powershell
.\start.bat --save-dir "D:\Civ6Saves"
```

**第一次加载较慢？**

大量存档需要逐一解析。解析结果保存在 `cache\replay.sqlite`，后续加载通常更快。关闭程序后可以删除这个缓存，但下一次会重新解析。

**地图或某项产出显示不可用？**

查看界面提示的具体原因，检查存档玩法、模组及数据库规则集。对于 BBG / CCB，可尝试按上述步骤采集相符的数据库；尚未实现的效果仍会提示缺项。
